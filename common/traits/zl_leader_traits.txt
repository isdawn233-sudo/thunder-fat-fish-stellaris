# ============================================================================
#  大肥鱼 天枢执政 —— 自定义领袖特性
#  Mod: zl_unique_administrator   (Stellaris Cetus v4.3.7)
#
#  ── ★★ 为什么必须严格守住槽位上限 ★★ ────────────────────────────────
#  原版 common/defines/00_defines.txt：
#      MAX_BASIC_TRAITS   = 2
#      MAX_VETERAN_TRAITS = 3
#  destiny 槽 1 个，subclass 槽 1 个。
#
#  ⚠ 实测踩坑：配装一旦超限（例如 veteran=4、destiny=3），
#    把领袖【任命到内阁】时游戏会执行槽位清理 —— 超出的特质被移除，
#    并且重新弹出"请选择特质"。所以超限【不能接受】。
#
#  但 10 级又要消耗 10 次选择（LEADER_TRAIT_SELECTION_LEVELS = 1..10）…
#  解决办法：不给满 10 个特质，改用 add_skill_without_trait_selection
#  直接把等级补到 10，从而绕开选择流程（见 effects 文件）。
#
#  ── 每个形态配装（7 个，符合全部上限）────────────────────────────────
#      basic 2 + veteran 3 + destiny 1 + subclass 1 = 7
#
#  ── 设计原则 ──────────────────────────────────────────────────────────
#  1) 不朽不靠寿命：特质带 immortal_leaders = yes（全局生效），
#     全部【不含 leader_lifespan_add】。
#  2) 不要经验加成：全部【不含 species_leader_exp_gain】。
#  3) 只有行政官有治理定位：
#         行政官  modifier + planet_modifier + sector_modifier
#         指挥官  modifier + fleet_modifier
#         科学家  modifier
#  4) COUNCIL = no（避免无职时显示灰色 X）
# ============================================================================
