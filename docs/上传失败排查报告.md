# Stellaris 创意工坊上传失败 —— 排查报告

> 提交给 Paradox 官方论坛 / Stellaris Modding Den Discord 的求助帖草稿。
> 所有日志与验证结果均为实测，附命令可复现。

---

## 一、结论摘要

**Paradox Launcher 无法为 Stellaris 创建 Steam 创意工坊条目。**

- 每次点「上传 MOD」都会失败，报 `k_EResultFileNotFound` 或 `k_EResultInvalidParam`
- **一个 2.6 KB 的最小测试 mod 也同样失败** → 与被上传的 mod 内容无关
- 启动器写入 `descriptor.mod` 的 `remote_file_id` **全部是无效 ID**
  （用 Steam API 验证：要么不存在，要么属于**其他游戏**）
- 已排除：mod 结构、编码、缩略图规格、磁盘空间、Steam 账号所有权、云同步、
  启动器缓存损坏、重复 mod、权限、是否经 Steam 启动

**目前唯一成功的上传**是通过 Steam 网页手动创建条目，但**该条目被创建成了
「Steam 艺术作品」（consumer_app = 767）而不是 Stellaris（281990）**，
因此启动器拒绝更新它（`Consumer AppIDs not matching`）。

**关键：每次的 ID 都不同，且都在旧 ID 上递增。**
（`31478521102` → `31481521102`，只差一位数）

### 2. 用 Steam 官方 API 验证这些 ID

`POST https://api.steampowered.com/ISteamRemoteStorage/GetPublishedFileDetails/v1/`

| 条目 ID | `result` | `consumer_app_id` | 说明 |
|---|---|---|---|
| `1623423360`（UI Overhaul Dynamic） | `1` | `281990` | ✅ 存在，属于 Stellaris |
| `24234243` | `1` | **`620`** | ⚠️ **Portal 2 的条目** |
| `32535324` | `1` | **`1250`** | ⚠️ **Killing Floor 2 的条目** |
| `1145149178` | `9` | — | ❌ 不存在 |
| `31478521102` | `9` | — | ❌ 不存在 |
| `31481521102` | `9` | — | ❌ 不存在 |
| `12423356` | `9` | — | ❌ 不存在 |

**启动器"创建"出来的 ID，要么不存在，要么属于完全无关的游戏。**

### 3. 启动器日志 `launcher-v2\logs\launcher-*.log`

```
[PublishModHandler]: Publishing mod started
[SteamErrorsLogger]: Error from Steam: k_EResultInvalidParam
[PublishModHandler]: Failed to publish mod:
    Publishing mod to Steam failed: Mod update upload to Steam workshop failed:
    Steam reported an error: A parameter is incorrect.
    Additional information: Updating Workshop item failed
```

以及手动创建条目后的明确报错：

```
[23:17:07] [AppID 281990] Upload starting for workshop item 3814700685 by AppID 281990
[23:17:07] [AppID 281990] Consumer AppIDs not matching ( expected 767 )
```

**启动器自己说：条目 `3814700685` 期望的 consumer AppID 是 `767`，不是 `281990`。**

### 4. 两种错误码的对应关系

| 情况 | 错误码 | 原因 |
|---|---|---|
| `descriptor.mod` 里**没有** `remote_file_id` | `k_EResultInvalidParam` (8) | 启动器尝试创建条目 → 拿到垃圾 ID |
| `descriptor.mod` 里**有** `remote_file_id` | `k_EResultFileNotFound` (9) | 启动器走"更新"路径 → 该条目不存在 |

按 [Steam Workshop Error Codes 文档](https://github.com/JDeffner/paradox-modding-toolkit/wiki/Steam-Workshop-Error-Codes)：

- `k_EResultInvalidParam` — *"Steam 拒绝了条目 ID 或某个字段。
  descriptor 里的工坊 ID 必须属于这个游戏。"*
- `k_EResultFileNotFound` — *"Steam 无法读取预览图，或该条目的工坊页面已不存在。"*

## 八、附：复现步骤

```powershell
# 1. 查看 Steam 侧上传日志
Get-Content "D:\Steam\logs\workshop_log.txt" | Select-String "281990" | Select-Object -Last 10

# 2. 查看启动器侧错误
Get-Content "C:\Users\<你>\AppData\Local\Paradox Interactive\launcher-v2\logs\launcher-*.log" |
    Select-String "PublishModHandler|SteamErrorsLogger" | Select-Object -Last 10

# 3. 验证某个工坊 ID 是否属于 Stellaris
$id = "3814700685"
(Invoke-RestMethod -Uri "https://api.steampowered.com/ISteamRemoteStorage/GetPublishedFileDetails/v1/" `
    -Method Post -Body "itemcount=1&publishedfileids[0]=$id").response.publishedfiledetails[0] |
    Select-Object result, consumer_app_id, title
```
